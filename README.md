# WorldCup

2026 世界杯赛事终端 Web Demo。

## 功能

- 首页赛事终端 Dashboard
- 下一场比赛倒计时
- 今日赛程动态
- 球队关注榜
- 小组热力图与小组积分榜
- 最佳第三名排名
- 晋级路径图
- 收藏比赛 / 关注球队，使用 localStorage 保存
- 移动端底部导航
- 深色/浅色切换

## 本地运行

```bash
npm install
npm run dev
```

## Vercel 部署

在 Vercel 中 Import Git Repository，选择本仓库即可。默认配置：

- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
